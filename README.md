# 🟣 Clone-Discord

Clone do design e interface do **Discord**, desenvolvido para treinar **responsividade em dispositivos Android** e reforçar conhecimentos em **HTML, CSS e JavaScript**.

A interface imita a aparência visual do Discord, com foco no layout responsivo e adaptação para telas pequenas 📱.

🔗 **Acesse a versão online:** https://clone-discord-iota.vercel.app

---

## 🎯 Sobre o Projeto

Este projeto é uma réplica visual da interface do Discord com foco em:

- 📱 **Responsividade** para dispositivos móveis (especialmente Android)
- 🧱 Estruturação de layout moderno usando componentes visuais parecidos com o Discord
- 🎨 Estilização com **CSS avançado**
- 🧠 Aplicação de boas práticas de front-end

Ele **não é funcional** como o Discord original — ou seja, não possui back-end, autenticação ou chat em tempo real — é um exercício de UI/UX e responsividade.
